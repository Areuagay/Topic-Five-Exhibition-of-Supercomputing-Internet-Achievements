# 上传模拟文件

六个领域、12 个场景的 **33 个可上传项**均有对应的小规模样例。内置数据项不要求上传，不在此样例清单中。

| 领域 | 上传样例数 |
| --- | ---: |
| 地球动力学 | 6 |
| AI 模型训练 | 5 |
| 汽车设计 | 7 |
| 仿真计算 | 5 |
| 药物设计 | 5 |
| 材料计算 | 5 |

## 页面操作

1. 打开应用场景的「输入数据」，所有可上传项默认使用本目录的对应文件，可直接预览、导入。默认下载名称与中文数据项一致；页面不增加单独的样例下载入口。
2. 点击「更换文件」选择自己的文件，单文件不超过 5 MB。CSV、JSON 及其他文本使用 UTF-8 编码。
3. 后端根据所选数据项校验内容、必需字段/列和基础数值，不依据文件名或扩展名判断。成功后保存实际文件，更新大小与记录规模，并自动打开预览。
4. 列表和预览展示当前文件名，可下载当前使用的原文件。刷新页面、重启服务后仍可预览；更换失败或取消不会清除原数据。
5. 用户文件的预览中提供「恢复默认」，恢复该项默认文件并清除该项导入状态。更换文件成功后也需要重新导入该项。

上传内容保存在 `.runtime-data/uploads/`，元数据保存在 `.runtime-data/{domain}.json`，不会覆盖仓库样例。旧版没有实际上传文件的空条目自动采用默认数据；已有用户文件保持不变。若已记录的用户文件在磁盘上丢失，则仍显示待上传，不悄悄替换为默认文件。

## 支持的预览

- CSV：前 50 条数据的表格；台站数据增加 x/y 平面分布，走时数据增加走时散点预览。
- JSON：格式化结构文本（最多 30,000 字符）。
- PDB：前 50 个原子的坐标表。
- SDF、UPF：结构文本；只做基础结构校验，不保证求解器兼容。
- Safetensors：张量名称、数据类型、形状与字节数，不加载模型执行推理。
- LSDA：专用二进制显示文件信息，可下载查看。`DS-CRASH-0002.json` 是明确标注的 JSON 小网格演示替代，包含 4 个节点和 1 个单元，**不是 LSDA 文件**。

这些文件用于上传、校验和预览演示，不是生产计算输入。PDB 是小片段，Safetensors 是微型张量；UPF 仅展示文件结构，不是完整可计算赝势。上传不会自动产生科学计算结果，现有后续计算流程仍使用模拟引擎。

## 地震波样例约定

- `DS-WAVE-0004.csv` 表头：`station_id,x,y,z,elevation_m`。10 个台站，局部直角坐标，单位米，z 向上。
- `DS-WAVE-0005.csv` 表头：`pick_id,station_id,phase,travel_time_s,confidence`。10 条 P 波初至记录，通过 `station_id` 关联台站。
- `DS-WAVE-0002.json` 约定震源在 `(1000,250,-1000)` 米，演示 P 波速度为 3000 m/s。
- 初至走时由震源到台站的直线距离除以该速度得到，无随机噪声；这是均匀介质近似，不是内置三维分层模型的求解结果。
- 置信度为演示固定值 0.95，不代表模型实际评估。

其他 CSV 的第一行就是上传表头；JSON 样例展示必需字段。校验以对应样例的字段及基础类型为准，允许附加字段。样例中的 `dataset_id`、`scenario_id`、`source_type` 不参与业务内容校验，可省略。文件名可自定义，无需匹配样例名称或编号。专业约束及跨文件完整性不属于通用上传校验的保证范围。

## 接口与生成

以 `/api/v1/{domain}/datasets/{dataset_id}` 为前缀：

| 方法与路径 | 行为 |
| --- | --- |
| `GET /sample` | 下载对应模拟样例 |
| `POST /upload?filename=...` | 请求体为文件原始字节，Content-Type 为 application/octet-stream |
| `GET /preview` | 返回受限长度的结构化预览 |
| `GET /download` | 下载当前默认文件或上传的原文件 |
| `DELETE` | 移除用户上传文件、恢复默认文件并清除该项导入状态 |

数据项的 `input_source` 为 `builtin`、`default` 或 `upload`；`uploaded` 表示已就绪，默认文件也为 true。`file_name` 是当前下载名称，`upload_format` 是实际文件格式（例如 LSDA 网格的默认演示文件为 JSON）。

清单位于 `manifest.json`。运行 `node scripts/generate-upload-samples.mjs` 可确定性地重建全部样例与清单；该命令会覆盖本目录的样例文件，不影响用户上传。
